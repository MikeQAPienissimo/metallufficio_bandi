DEPLOY NETLIFY:
1. Vai su https://app.netlify.com/drop
2. Trascina l'intera cartella oppure il contenuto estratto dello ZIP.
3. Netlify genera subito un URL pubblico.
4. In Site configuration > Change site name puoi impostare, se disponibile:
   metallufficio-bandi-2026
5. URL finali:
   https://NOME-SITO.netlify.app/
   https://NOME-SITO.netlify.app/cciaa.html
   https://NOME-SITO.netlify.app/fesr.html

I collegamenti interni sono relativi, quindi funzionano anche cambiando il dominio.
Il logo ufficiale Metallufficio è incorporato direttamente negli HTML.
